SysInfo: Inventario de PC con PowerShell

Proyecto académico para consultar información del sistema operativo, las políticas de ejecución y el hardware de una PC.

Objetivos del proyecto

  • Consultar la versión y edición de PowerShell.
  • Identificar las políticas de ejecución de scripts.
  • Obtener información de Windows y su arquitectura.
  • Consultar procesador, memoria RAM, placa base y discos.
  • Identificar los adaptadores de red.
  • Complementar los datos con el comando systeminfo de CMD.
